## À propos

Le design s'inspire du pseudocode utilisé dans mes cours d'algorithmique — la page se lit comme un algorithme (`Var`, `Debut`, `Fin`), avec la déclaration `<----` pour styliser les informations clés.

## Fonctionnalités

- Thème clair / sombre avec sauvegarde de la préférence (`localStorage`)
- Menu mobile responsive en CSS pur (sans JavaScript)
- Animations d'entrée et effets de survol
- Une seule page, navigation par ancre

## Stack technique

- HTML5 / CSS3 (variables CSS pour le theming)
- JavaScript vanilla (toggle de thème uniquement)
- [Font Awesome](https://fontawesome.com/) pour les icônes
- Polices : Audiowide, Inter, JetBrains Mono
